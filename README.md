# ARGB Krutoy

Windows-приложение для музыкальной RGB-подсветки.

## Важно
Первая рабочая версия использует OpenRGB SDK как временный драйвер устройств. Это позволяет проверить захват системного звука и эффекты на твоём ПК, но **пока не является полностью независимым управлением железом**. Прямой драйвер для Gigabyte B760M, RTX 3060 и ENE DRAM требует отдельной реализации и проверки на реальном оборудовании. Программа не пишет напрямую в SMBus и не использует опасные низкоуровневые обходы.

## Что есть
- Захват звука Windows через loopback.
- Реакция на громкость/бас.
- Отдельное окно, эффекты Spectrum/Bass Pulse.
- Подключение к локальному OpenRGB SDK для управления совместимыми RGB-устройствами.

## Запуск
1. Установи Python 3.11 или 3.12 x64.
2. Установи и запусти OpenRGB, включи SDK Server (обычно порт 6742).
3. Скачай ZIP репозитория или клонируй его.
4. Запусти run.bat.

Настройки RGB-программ могут конфликтовать — на время теста закрой GCC и Nexus. Не запускай несколько программ, которые одновременно управляют одними и теми же устройствами.
